# iac-ec2-and-fargate-deployment-terraform-laravel-multiple-queues
This project involves a Terraform Infrastructure-as-Code (IaC) setup that supports both EC2 and Fargate, with configurations for two environments: staging and production. It is designed for a Laravel application and includes PHP, Nginx, and SQS. The IaC is structured to manage multiple SQS workers (low, medium, high) efficiently.
